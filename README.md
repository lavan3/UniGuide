# UniGuide
## Our inspiration
As students, we know firsthand how frustrating and overwhelming it can be to find university resources for your specific situation: 
- University websites are notoriously clunky and difficult to navigate
- Information can be cluttered and/or scattered
- AI tools and search engines require knowing the right questions to ask!
- Academic advisors and student help desks can be less convenient, or even a barrier, for some students

We wanted to answer the question: "How can university resources be more accessible for all students?"

## What it does
UniGuide is an web app that helps students identify the specific resources they need. An interactive quiz helps students focus in on the type of support best suited to the task. Based on student input, relevant resources are presented in an organized, curated manner. With our app, students will be able to access university resources more efficiently and effectively.

## How we built it
Server-side JavaScript runtime: 
- Deno

Frontend UI and JavaScript: 
- HTML, CSS, React

Course Information retrieval: 
- Groq AI API

## Challenges
- Connecting the backend AI API to the frontend components
- Effectively troubleshooting bugs remotely over video call
- Tokenizing and formatting the chatbot responses

## What's next for UniGuide
Ideally, the external API component in our application would be replaced by a specialized ‘in-house’ LLM that has been trained on data related to university websites. We may potentially want to integrate a persistent database of university resources into the backend for faster, more efficient responses.
